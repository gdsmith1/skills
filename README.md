# skills

Custom Claude Code skills that aren't specific to any project. Each top-level folder is one plugin, with its skills under `skills/`.

- `.github/workflows/release.yml` tags and releases on every push to `main`. `actions.lock` is generated by `gh actions-lock`, so don't edit it by hand. `dependabot.yml` keeps the pinned actions current.
- Each plugin folder has a `.claude-plugin/plugin.json` manifest.
- Each `skills/<name>/SKILL.md` is a skill. `reference/` folders hold the output formats a skill points to.
- `AGENTS.md` points agents at this README.

## Releases

Pushes to `main` run `release.yml`. It bumps the version from conventional commit messages, pushes a tag, and creates a GitHub release with `gh`.
