# skills

Custom Claude Code skills that aren't specific to any project. Each top-level folder is one plugin.

## Install

Add the marketplace once, then install each plugin you want. Run these in a Claude Code session:

```
/plugin marketplace add gdsmith1/skills
/plugin install pptx-to-html@gdsmith1
```

To confirm it worked:

- `/plugin marketplace list` shows `gdsmith1`.
- `/plugin` shows `pptx-to-html` as installed and enabled.
- From a shell, `claude plugin list` shows `pptx-to-html@gdsmith1` with status enabled.

Start a new session after installing so the skill loads.

## Updates

Updates aren't automatic by default. To get the latest:

- In a session, run `/plugin marketplace update gdsmith1`. From a shell, run `claude plugin update pptx-to-html@gdsmith1`.
- To have updates install in the background, run `/plugin`, open the **Marketplaces** tab, select `gdsmith1`, and choose **Enable auto-update**.

A plugin only updates when its `version` in `plugin.json` changes.

## Where to look

```
.
├── .claude-plugin
│   └── marketplace.json        # marketplace catalog; lists the plugins this repo publishes
├── .github
│   └── workflows
│       ├── actions.lock        # generated by `gh actions-lock`; never edit by hand
│       └── release.yml         # tags and releases on every push to main
├── <plugin>                    # one folder per plugin
│   ├── .claude-plugin
│   │   └── plugin.json         # plugin manifest; read first to see what the plugin provides
│   ├── hooks                   # optional; hook config and scripts that run on tool calls
│   └── skills
│       └── <skill>
│           ├── SKILL.md        # the skill's instructions; the main thing to read
│           ├── reference       # optional; output formats and examples the skill points to
│           └── scripts         # optional; helper scripts the skill runs
└── README.md                   # this file
```

## Releases

Pushes to `main` run `release.yml`. It bumps the version from conventional commit messages, pushes a tag, and creates a GitHub release with `gh`.
